## Decisions & Rationale

- Used a 5-column × 4-row layout with 20 square 256×256 cells, producing uniform 1280×1024 RGBA assets.
- Used the built-in GPT Image path and flat #00ff00 backgrounds, then local chroma-key removal, as required by the image-generation skill.
- Gated the manifest to the exact blue Azureus source path so other Azureus colors do not incorrectly display blue animations.
- Used canvas source-rectangle rendering instead of compressing the whole sheet into an img element.
- Kept the static image visible until a sheet is decoded and restored it on completion, cancellation, missing-sheet fallback, or error.
- Suppressed legacy prop graphics only after sprite playback actually starts; non-HP stat items retain the existing behavior.
- Preserved the original outbound frisbee flight, then switches to the baked fetch sequence; cancellation prevents rewards and stale repositioning.
- Did not alter or discard unrelated dirty-worktree changes.
