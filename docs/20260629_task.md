## Decisions & Rationale
A generation is counted only when the current pairing is one of the requested close relationships. Generation 1 covers full siblings with both known parents matching and direct parent/child pairs. If a close pair includes a pet produced by an earlier close pairing, the generation increments from the highest parent generation. Pairing with an unrelated pet returns generation 0, which supports the requested diverse-gene-pool incentive instead of carrying a permanent penalty.

Unknown fathers are not treated as matching parents, so two pets with the same mother and null daycare-stallion fathers are not guessed to be full siblings. No database column was added: generation remains reproducible from `pet_parentage`, avoiding duplicated state that could drift from the family graph.

The selected stat is the hatchling's highest stat after ordinary randomization and parent-stat bonuses. Generation 1 rounds 150% to the nearest integer; generation 2+ rounds 50% to the nearest integer with a minimum of 1. If maximum HP is selected, current HP is updated to the same value.
